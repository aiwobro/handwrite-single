将已有文字排版到纸张模板上，生成带有程序模拟手写效果的会议资料，用于打印、阅读和创意展示。本工具不录音、不转写，也不会自动编写或核实会议内容。

一、准备内容与选择纸张

先整理正文，确认文字准确、可公开使用且不含机密信息。在工具首页点击模板卡片选择纸张；预览图可放大查看。不同模板的尺寸、行数和正文区域不同，同样的文字可能生成不同页数。

默认会议记录本具有正反面布局和首页会议信息区域；单面 18 行纸使用同一纸张布局续页，不提供会议信息栏。请以所选模板及实际生成结果为准。

二、填写或导入正文

  1. 粘贴正文，或点击“导入 TXT”选择本地 UTF-8 文本文件。TXT 在浏览器中读取并填入文本框；点击生成后，其正文才随表单提交到服务器。
  2. 使用换行划分段落。程序会自动排版、分页，并尽量处理常用中文标点的行首、行尾禁则。
  3. 正文为必填项，当前上限为 {{ max_content_chars }} 字符，最多生成 {{ max_generated_pages }} 页。字符数未超限也可能因换行过多或模板容量不足而超过页数限制。
  4. 可填写日期、地点、标题、主持人、记录人和参会人。日期默认当天；不需要的字段可清空。仅有对应区域的模板会渲染这些字段。

首页会议信息区域空间有限，过长内容可能被截断。建议使用简短标题和必要的姓名信息，生成后认真检查。

三、生成、预览与导出

  1. 点击“开始生成”，保持页面打开。耗时与正文、页数、模板尺寸和服务器负载有关。
  2. 当前加载提示是按时间切换的阶段说明，不是真实任务进度或完成时间承诺。
  3. 生成后点击缩略图查看大图，使用缩放、拖拽及前后翻页检查内容。
  4. 下载 PDF 用于多页打印，下载 ZIP 获取全部 JPG 页面，也可以在大图预览中保存单页。若 PDF 导出失败，图片仍可能正常下载。
  5. 点击“换一种笔迹”会用当前表单重新生成，随机字距、角度和墨色可能变化，分页也可能改变；这不代表模仿某个真实人物的笔迹。

四、打印建议

先试印一页。根据纸张与打印机设置选择“适合页面”或实际尺寸，检查缩放、方向和边距。双面打印时确认翻转方向与模板顺序；单面模板不会自动要求打印机双面打印。PDF 是页面图像导出，不是可编辑的文字文档。

五、草稿、重置与常见问题

  • 刷新后文字还在？草稿保存在当前浏览器标签页的 sessionStorage 中；共享设备使用后请重置并清理站点数据。
  • “清空正文”与“重置全部”有什么区别？清空正文只清除文本框；生成后的“重置全部”清除当前页面状态和该标签页草稿，不删除服务器上已经生成的文件。
  • 生成失败？先减少正文和空行，检查日期，或换用容量更合适的模板；仍失败可通过项目问题反馈入口报告。不要附上真实会议内容或下载链接。
  • 能一直保存结果吗？不能保证。请及时下载；服务不是备份工具，目前也没有固定的自动删除期限。
