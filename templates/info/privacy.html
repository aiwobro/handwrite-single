本政策说明当前 Handwrite Studio 网页服务的数据处理方式，不适用于您自行部署的其他实例或第三方网站。请在提交前阅读；如果无法接受以下保存与访问方式，请勿上传资料。

一、重要提示

当前生成文件没有账号级访问控制，知道结果链接的人可能直接访问文件；随机文件名不是可靠的权限保护。当前也未实现固定期限自动删除。请勿提交国家秘密、商业秘密、未公开会议资料、身份证号、健康及财务等敏感信息，或无权处理的他人个人信息。

二、处理哪些数据以及用途

  • 表单数据：点击生成时，正文、所填会议信息及模板选择会发送至服务器，用于校验、排版、渲染及错误处理。请仅填写完成任务必要的信息。
  • 生成文件：JPG、PDF 以及按需创建的 ZIP 保存在服务器 output 目录，文件内会包含您提交的可见文字。
  • 技术数据：承载服务的服务器、反向代理及适用的网络服务商可能处理 IP 地址、请求时间、访问路径、浏览器信息、响应状态等，用于提供服务、运维排错和安全防护。异常日志也可能包含相关技术上下文。

应用当前不要求注册，不专门建立原始正文数据库，也不主动将正文写入会话 Cookie；但这不等于正文没有上传或没有被保存，生成文件本身会保留内容。

三、浏览器草稿与 Cookie

网页使用 sessionStorage 在当前标签页保存完整表单草稿，包括正文和会议信息，用于刷新后恢复。它不是服务器草稿库，也不会跨设备同步。关闭标签页通常会结束该存储会话，但浏览器恢复标签页等行为可能恢复数据；请不要仅依赖关闭窗口来清除资料。

Flask 会话 Cookie 用于保存部分表单字段、错误状态和结果标识。该 Cookie 有签名但不是加密存储，不应被视为机密保险箱。浏览器会在访问本站时自动发送适用 Cookie。

“清空正文”只修改正文及本地草稿；“重置全部”会清除当前页面会话状态和该标签页草稿。两者均不会删除服务器已有输出。您也可以在浏览器设置中清除本站 Cookie 和站点存储，这可能导致当前结果入口无法恢复。

四、保存期限与删除

当前输出文件没有固定自动过期时间，可能保留至维护者手动清理、服务迁移或存储维护。我们不承诺永久保存、固定时间删除或恢复已丢失文件，请及时下载必要结果。技术日志的保留期限取决于实际托管和运维配置，目前未设统一的对外期限。

如希望申请访问、更正或删除与您有关的信息，可通过关于本站中的反馈入口先提出脱敏联系请求。处理前可能需要合理核实请求人与文件的关系；可处理范围取决于现有数据及法律要求。请勿公开粘贴结果链接或个人资料。

五、共享、第三方与数据位置

当前应用未接入广告联盟、第三方行为分析或大模型处理服务，不将会议正文用于广告画像或模型训练。必要的托管、网络传输和安全服务提供方可能在其服务范围内处理技术数据；依法配合有权机关的要求或处理安全事件时，也可能需要提供必要信息。

服务器和网络基础设施所在地可能与您的所在地不同，目前不提供指定地域存储保证。外部 GitHub 链接适用其自身隐私政策。未来如引入广告、分析或其他数据用途，将更新说明，并在适用法律要求下提供相应告知和同意机制。

六、安全、未成年人和政策更新

线上服务使用 HTTPS 传输，但任何网络服务都无法保证绝对安全。请妥善保护设备和下载文件，不在公共设备上保留资料。未成年人应在监护人指导下使用，不应提交本人或他人的敏感个人信息。

本政策会随功能和部署调整更新，页面标明最新日期；涉及实质性数据处理变化时，将按适用要求另行告知或征求同意。如有疑问，请先查看关于本站与反馈方式。
